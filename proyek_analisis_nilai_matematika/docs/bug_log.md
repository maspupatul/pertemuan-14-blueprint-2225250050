# Bug Log

Catat bug berdasarkan kejadian yang benar-benar ditemukan saat menjalankan program.

| ID | Gejala | Penyebab | Perbaikan | Status |
|---|---|---|---|---|
| BUG-01 | Belum ada bug yang dicatat | Belum diperiksa | Jalankan program dan test case; tambahkan catatan jika menemukan bug | Belum diuji |

Jangan mengarang bug. Jika pengujian tidak menemukan bug, jelaskan bahwa pengujian awal tidak menemukan bug dan isi tabel berdasarkan hasil nyata.
